# NET377 – Network Security Projects

> A collection of Cisco Packet Tracer network security labs completed for **NET377 – Network Security** at **DePaul University**. These projects focus on secure network architecture, firewall deployment, Network Address Translation (NAT), static routing, IPsec VPNs, and enterprise network design.

---

## Course Topics

Throughout this course I gained practical experience with:

- Cisco IOS router configuration
- Cisco ASA Firewall configuration
- Static Routing
- Access Control Lists (ACLs)
- Network Address Translation (Static NAT, Dynamic NAT, PAT)
- Stateful Firewall Policies
- Enterprise DMZ Architecture
- Split Firewall Design
- Site-to-Site IPsec VPN
- Enterprise Network Design
- Secure Traffic Flow Analysis
- Cisco Packet Tracer Network Simulation

## 2. Cisco ASA Firewall, ACLs & NAT

This project introduces perimeter security using a Cisco ASA firewall.

### Technologies

- Cisco ASA Firewall
- Static NAT
- Dynamic PAT
- ACLs
- Stateful Inspection
- Static Routing

### Implemented Features

- Inside and Outside security zones
- Static NAT for public server publishing
- Dynamic PAT for internal clients
- Access Control Lists
- HTTP
- SSH
- ICMP filtering
- Internet connectivity validation

---

## 3. Cisco IPsec Site-to-Site VPN

A secure VPN tunnel connecting two remote private networks across an untrusted public network.

### Technologies

- ISAKMP (IKE Phase 1)
- IPsec ESP
- AES-256 Encryption
- SHA Authentication
- Pre-Shared Keys
- Crypto Maps
- ACL-based Interesting Traffic

### Implemented Features

- Secure site-to-site VPN
- Tunnel establishment
- Encrypted inter-site communication
- Secure routing between private LANs
- VPN traffic verification

## 5. Enterprise Infrastructure Design Project

This repository contains the **final prototype** developed throughout the course.

The project evolved in two stages:

### Prototype Phase (Lab 3)

Designed and implemented the complete enterprise network architecture.

Included:

- Enterprise topology
- IP addressing plan
- Static routing
- NAT design
- Traffic flow validation
- Multi-subnet architecture
- DMZ deployment

### Security Implementation (Lab 6)

Expanded the prototype by implementing enterprise firewall security.

Included:

- Layered firewall architecture
- ACL implementation
- Enterprise firewall rules
- Secure traffic filtering
- Network segmentation
- End-to-end security testing

### Enterprise Components

- HQ Network
- Remote Site
- Internet Edge
- DMZ
- Internal Network
- Active Directory
- HR Server
- Database Server
- Web Security Appliance
- VPN Connectivity
- Layer-3 Switching
- Firewall Policy Enforcement
